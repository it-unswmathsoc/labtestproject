# MathSoc Lab Test Practice — Frontend

A [Next.js](https://nextjs.org) frontend for the UNSW MathSoc lab test practice platform, letting students author and preview practice questions modelled on the maths lab tests.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Branches

- **`main`** — the default branch. Reviewed, integration-ready work lands here.
- **`labtest-frontend-cheng`** — active working branch for frontend development; opened as PRs against `main` for review.

## Scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Start the development server |
| `npm run build` | Production build |
| `npm test` | Run the test suite (Vitest) |

## Tech Stack

- Next.js 16 (App Router)
- TypeScript
- Vitest for testing
